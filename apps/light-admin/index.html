Add a tenant

The base URL is the tenant's OData root (it ends in /c4codataapi). The password is encrypted on the server and never shown again; when editing, leave it blank to keep the current one.

Tenants

One tenant is active at a time: every lookup and write from the extension and the field app goes there, and switching takes effect immediately. Writes to a tenant tagged production are refused unless the client explicitly confirms them. The encryption key lives in data/.tenant-key (or ADMIN_ENCRYPTION_KEY) — back it up together with the catalog.

People

Owner: everything. Admin: settings and users (managers and agents). Manager: read-only oversight. Agent: uses the extension and field app, including SAP writes. A deployment always keeps at least one active owner.
